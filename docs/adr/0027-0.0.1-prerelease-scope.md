# ADR-0027: 0.0.1 pre-release scope

- Status: Accepted; the two-repository publication clause is superseded by [ADR-0036](0036-single-repository-record.md) — the 0.0.1 host-scope decision stands
- Date: 2026-08-14
- Deciders: user (approved via release questionnaire) + assistant session

## Context

ADR-0014 §7 sets the full four-year Windows host matrix (AE 2023-2026) as a
release gate. Reality at 0.0.1 time: AE 2025 and AE 2026 carry complete
M1-M7 verification batteries on the release artifact; AE 2023 is `BLOCKED`
by the host itself (23.0 fast-fails at launch on the dev machine with and
without the plugin — A/B measured 2026-08-14, exit 0xC0000409); AE 2024 has
no host installed. The user directed a public 0.0.1 release now.

## Decision

- 0.0.1 ships as a **pre-release** whose supported-host claim is exactly the
  verified set: Windows After Effects 2025 and 2026. Release notes state
  this and the 2023/2024 status truthfully.
- ADR-0014 §7's four-year gate is **not** superseded; it remains the gate
  for 1.0. This ADR scopes pre-releases only: a pre-release may ship with
  the verified subset, provided every shipped-host claim carries its
  evidence chain and unverified hosts are named as such.
- The public distribution is a curated repository (code + user-facing docs
  + MIT license) plus a packaged AEX release. The internal governance
  corpus (ADRs, audits, test matrix, evidence) remains in the private
  development repository — it cites competitor research and machine-local
  detail the user chose not to publish. Public claims must still trace to
  private evidence records.
- License: MIT (user's choice).

## Consequences

- Users on AE 2023/2024 are not promised anything at 0.0.1; the README and
  release notes carry the verified-host table.
- 1.0 requires the full matrix per ADR-0014 §7 (2023 retest after the host
  itself is fixed/updated; 2024 when a host exists).
- The curated public repo starts a fresh history; the private repo remains
  the authoritative record. Divergence is prevented by releasing from
  private-repo state only.
