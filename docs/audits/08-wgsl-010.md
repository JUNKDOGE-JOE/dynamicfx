## Outcome

Production WGSL is implemented and its CPU/Metal checks pass. The native
0.1.0 candidate `91c8afd...` was installed after administrator authentication.
Its 217 scripted AE assertions pass, but real Language Undo fails and leaves

writes. This candidate cannot be published; a supervised-callback and idle
publication repair is being prepared for a new installed-artifact acceptance.
The replacement is now built from `f4ba578552e02c2a82170d2d116cf0400d8319a6`:
default/editor each pass 213 tests, executable SHA-256
`661e89af6aa6c9cb595732146b01a42a4dad99fd1d6a19929723622a8f2a7371`.

pending; this is not a release PASS.** Verification authority is

## Code paths and contracts

[ADR-0044](../adr/0044-wgsl-and-010-release.md) activates stable ID 2, appends
WGSL after the unchanged GLSL default, and specifies the release subset.
[wgsl.rs](../../src/frontend/wgsl.rs) parses original WGSL IR;
[shared.rs](../../src/frontend/shared.rs) reflects the parameter/annotation
model shared with GLSL. Graph execution, SPIR-V emission, upload and renderer
remain shared; there is no generated GLSL schema in this compiler.

Unsupported stages, entry/IO shapes, resources, address spaces, bindings,
overrides and optional f16/subgroup capabilities are rejected. The uniform
head remains at 0/8/12; native offsets and explicit padding are reflected,
with a 64 KiB limit before GPU allocation. Envelope `@@` escaping is unchanged.
E21 identifies WGSL parse/validation errors; E18/E19/E20 retain their meanings.
Diagnostics report pass-local locations and the original body-start line,
without presenting unescaped byte columns as original envelope columns.
Snapshots retain exact source, Language ID and binding plan; no schema change.

## Findings and failures

The [first production comparison](evidence/wgsl-010-20260908/gpu-first-instrument-failure/result.json)
failed because independently loaded GLSL lacked the parameter annotations
supplied to WGSL. The historical spike had passed shared annotations externally.
Supplying identical metadata yielded zero-error pairs with the same
runner/source identities. This was an instrument correction, not a runtime
fix; failing outputs remain preserved.

The examples' [log](evidence/wgsl-010-20260908/examples/renders.log) preserves
an initial sandbox failure to enumerate Metal, followed by successful runs
with GPU access. Their 8-bpc multipass output differs from float because of
intermediate clipping/quantization, with a recorded maximum difference about
0.0284. The limited mean-error check does not claim per-pixel depth equivalence.

The [independent review](evidence/wgsl-010-20260908/independent-review/review-notes.md)
found no new production defect and verified extraction of the original GLSL
reflection logic. A test-only escaping helper had a limitation for future
indented fixtures; this was not a production parser failure. Review and three
layout probes do not constitute exhaustive compiler fuzzing.

Publication review found historical third-party details in ADR-0033 and an
optional comparison script. Visible redactions follow ADR-0036; the script
now requires an explicitly supplied reference name. The dated
[preflight](0.1.0-release-preflight.md) records this and remaining publication
checks. Previously published history cannot be recalled.

## Known limitations and residual risks

Current-artifact AE 2026 still requires menu/defaults, publication, invalid
source, language switching, keyframes, real Undo/Redo, save/reopen,
Layer/Gradient/Path, temporal requests, reduced renders and independent
aerender acceptance. No such AE PASS is claimed here.

Windows 0.1.0 artifacts and Windows/DX12 acceptance remain NOT_RUN. Other AE
years, Intel/Rosetta and cross-GPU bit identity are not granted by these
results. The candidate is ad-hoc signed, not Developer ID signed or notarized;
the optional gradient editor is disabled in the release flavor. Candidate
archive/extraction checks pass; final release/tag and post-download verification
remain pending. Publication
and the actual iOS 27 Siri implementation have not started.

## Decision changes

ADR-0044 supersedes feasibility-only scope with production WGSL and an
authorized macOS-first 0.1.0 release. It does not add arbitrary WebGPU resource
interfaces, change the persistent schema, or grant untested host support.
Actual iOS 27 Siri implementation begins after release publication.

## Reproduction

Use the frozen compiled-source revision, retained lockfile and linked
fixtures. Run scripts into fresh output directories to preserve earlier
results. The evidence [README](evidence/wgsl-010-20260908/README.md) explains
float decoding and manifest verification. Native installation uses
`scripts/macos.py` against one explicit AE year; verify the installed hash
before host tests. Do not rebuild or re-sign accepted bytes when assembling
the eventual release archive.
