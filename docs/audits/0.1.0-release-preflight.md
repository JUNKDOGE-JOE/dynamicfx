## Checks and test boundary

The new [release preflight](../../scripts/release/preflight.py) is read-only:
no network, install, signing, git mutation or release action. Run it with:

```sh
python3 scripts/release/preflight.py --expected-version 0.1.0 --archive dist/DynamicFX-0.1.0-macos-arm64.zip
```

Optional `--restricted-terms-file` reads newline-separated private terms from
a local file; never commit that file. Output includes no matched text. The
script checks the candidate source version, credential patterns, ZIP member
safety, arm64 header, executable mode, required bundle files, package docs
and checksums. It explicitly does not claim native signature/notarization,
host behavior, source equivalence or release authorization.

Seven temporary byte-level fixtures passed: valid archive structure,
rejection of missing instructions, altered checksums, traversal paths,
Finder detritus, wrong version and a synthetic credential. Fixture binaries
and signatures were deliberately fake; these tests exercised archive rules
only. Python syntax/import succeeded without writing bytecode to the repo.

The release host gate is [ADR-0044's verification obligations](../adr/0044-wgsl-and-010-release.md#verification-obligations),
qualified only by [ADR-0045's Source Undo exception](../adr/0045-010-source-undo-release-boundary.md):
production direct WGSL parsing/reflection and ABI rejection, parameter layout,
source mapping, graph/persistence contracts; equivalent GLSL/WGSL GPU results
at 8/16/32-bpc; real AE menu/defaults/publication, keyframes, invalid source,
language changes, Undo/Redo, save/reopen, Layer/Gradient/Path resources,
temporal random-time requests, Full/Half/Quarter and independent aerender.
The final results and their Gradient UI-initialization and export-depth
boundaries are recorded in TR-WGSL-002 and the current update above. The old
184-test GLSL suite and feasibility spike are useful baselines, not proof of
the new frontend. Windows is explicitly deferred by the user; no
Windows PASS or Windows asset should be manufactured from Metal results.
